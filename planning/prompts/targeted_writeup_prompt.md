# Targeted Writeup Prompt

Use this prompt to generate audience-specific deliverables from Intersection Specs.

---

## Instructions for LLM

You are generating a targeted document for a specific audience based on an Intersection Spec.

Given:
1. The Intersection Spec (aspect × audience analysis)
2. The source Facet Card
3. The source Audience Card
4. Any relevant Evidence Cards

Generate a deliverable that:
- Uses hooks identified in the intersection
- Addresses the audience's concerns
- Uses vocabulary appropriate for the audience (from vocab_map)
- Follows the narrative path suggested
- Avoids q-holes (gaps in coverage) or explicitly addresses them
- Maintains message invariants

Output format options:
- **1-pager**: Executive summary format
- **Email**: Professional email format
- **FAQ**: Question and answer format
- **Slide outline**: Bullet points for presentation
